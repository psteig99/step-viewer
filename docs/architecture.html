Notes d'intégration
Minimum absolu : loader.py + analysis.py + server.py côté Python, viewer.js côté navigateur. Tout le reste se branche en important le module.
API Claude : analysis.js appelle POST /{id}/ai-analysis — remplacer l'URL suffit pour pointer sur un autre backend LLM.
Intégration externe : StepViewer.onModelLoad(cb) · StepViewer.captureAll() · StepViewer.getModelInfo()
Cache GLB : loader.py cache par path + taille + mtime + tolérance — rechargement immédiat si le fichier n'a pas changé.
